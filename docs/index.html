Setup — one real step, then let the agent do the rest

This is the single biggest predictor of whether the day works for you. An hour of setup trouble at 10am is an hour of the workshop you don't get back. The good news: only the first step is genuinely yours. Once you have an agent installed, it can do the rest of the setup for you — which is also your first taste of what these tools are for.

  1. Install a coding agent and sign in

    We'll be using Claude Code — it's what gets demonstrated from the front of the room, it's what the TAs can help you debug, and it's on the Institute's Claude Team plan (CONFIRM SEATS). The desktop app is the gentlest on-ramp; the command-line version works equally well if you live in a terminal.

    Already productive in Gemini CLI, GitHub Copilot agent mode, or Codex? Bring it. Everything taught that day is tool-neutral and transfers. Your mileage will vary on the exact commands in one mid-afternoon exercise, where the configuration file lives in a different place for each tool — we'll hand you the mapping for all four.

  2. Bring a laptop and a charger

    Outlets are not guaranteed to be within reach of every seat. If your setup dies on the day, pair with a neighbor — pairing is a feature, not a fallback.

  3. Hand the rest to the agent

    Open it and paste this in. It will check for git, install it if needed, download the workshop materials, and confirm it can read them:

    I'm attending a workshop on Thursday and need to get set up.
Check whether git is installed and help me install it if not.
Then clone https://github.com/golnazvahedi/epigenetics-agentic-workshop.git
into a sensible folder, and read track-a/data/README.md from it
and tell me in one sentence what differential_peaks.csv is.

    Expect it to ask permission before running commands. That's the sandbox working as designed, and saying yes here is fine — we'll talk on Thursday about when it isn't.

You're done when it comes back with a sensible answer about H3K27ac ChIP-seq peaks. That one reply proves the whole chain: the tool is installed, you're signed in, it can run commands, and you have the materials.

If it stalls, don't fight it — that's what the setup clinic at lunch is for. You can also just tell the agent what went wrong and let it troubleshoot; it is surprisingly good at diagnosing its own environment.

Never used a tool like this? That's the expected case, and the day is built for it. You do not need to know how to code. You do not need to have used a coding agent before. If you've ever typed a question into ChatGPT or Claude, you already have the skill that matters most.

What you take home

A working setup, not a memory

Each exercise builds something the next one uses. By 2pm you have a small working setup of your own — not notes about one.

Exercise 1Your ledger

A plain-text log of what you asked, what the agent did, and how you checked it.

Exercise 2A context file

What your agent should know about your project, written once instead of re-typed forever.

Exercise 3A skill

A procedure you write once and your agent runs on demand — in any project, on any tool.

The exercise briefs are at the workshop repository — you don't need them before Thursday.

The ledger is the thread, and it carries into the afternoon: whatever you pick after 2pm, log it the same way. It's how the day's one non-negotiable habit — verify before you trust — becomes something you do rather than something you were told.

Ground rules

Three rules for the day

  • Privacy. Do not put PHI, your own unpublished data, or grant drafts into any AI tool during the workshop. Every exercise ships with its own materials — real mouse datasets shared by the Vahedi lab for teaching, a simulated sample sheet, and an open-access paper — so you never need your own data. We'll cover what is safe, and how to find out, during the morning.
  • Verify. The recurring habit of the day. Whenever the agent produces a result, ask it "how do I know this is right?" and make it show its work. The datasets you'll be working with contain real traps, and that is deliberate.
  • Pair up. If your setup dies, share a laptop. Two people talking to one agent is often better than two people talking to two agents.
